
# Number Guessing Game 🎯

A console-based Number Guessing Game developed in C++.

## About

The player has to guess a randomly generated number within a limited number of attempts. The game provides different difficulty levels, hints, score calculation, input validation, and a replay option.

## Features

- 🎯 Multiple difficulty levels
- 🎲 Random number generation
- 🔢 Limited attempts
- 💡 Dynamic hint system
- 📊 Score calculation
- 🔁 Play again option
- 🚫 Duplicate guess detection
- ✅ Input validation
- 📐 Mathematical hints

## Difficulty Levels

- Easy: 1 - 50
- Medium: 1 - 100
- Hard: 1 - 500

## Hints

The game can provide different types of hints:

- Even or Odd
- Multiple of 2, 3, or 5
- Perfect Square
- Number Range
- Digit Sum

## C++ Concepts Used

- Functions
- Vectors
- Loops
- Conditional Statements
- Random Number Generation
- Input Validation
- Mathematical Operations
- References
- `const`
- `switch`-style decision making using `if/else`
- `do-while` loop
- Range-based `for` loop

## How to Run

1. Clone or download the repository.
2. Open `Number Guessing game.cpp` in a C++ IDE.
3. Compile the program.
4. Run the executable.
5. Select a difficulty level and start guessing.
